Project Overview & System Requirements

SparkEV unites offline model training (Python 3.10+, XGBoost, Elastic Net, Flower FL) with lightweight on-device inference on an ESP32 microcontroller at 240 MHz.

Server / Workstation Environment

  • • Python 3.10 or 3.11 (tested on 3.11.3)
  • • XGBoost 2.0+, Scikit-Learn 1.3+
  • • Flower (flwr) 1.6+ for Federated Learning
  • • FastAPI + Uvicorn for recommendation backend
  • • 8 GB RAM minimum (16 GB for multi-client FL)

On-Device Microcontroller

  • • Microcontroller: ESP32 Dual-Core @ 240 MHz
  • • Display: SH1106 OLED (128×64 I2C)
  • • C Header tree-traversal inference (no dynamic heap allocation)
  • • Total On-Device Inference Time: 8.65 ms
  • • Wi-Fi client transport (JSON payload to FastAPI)

Setup & Installation Instructions

Step 1: Clone Repository 
git clone https://github.com/Shravanthi20/spark-ev.git
cd spark-ev
Step 2: Configure Virtual Environment 
# Windows PowerShell:
python -m venv venv
.\venv\Scripts\Activate.ps1

# Linux / macOS:
python3 -m venv venv
source venv/bin/activate
Step 3: Install Core Dependencies 
pip install --upgrade pip
pip install -r requirements.txt

Instructions for Running Each Module

1. Run Module 1 Driving-to-Stress Training: 
python src/module1_driving/train_m1_xgboost.py --calibrated True
2. Run Module 2 Charging Anomaly Detection: 
python src/module2_charging/train_m2_anomaly.py --weight_ratio 8.765
3. Run Module 3 Direct AR SOH Forecasting: 
python src/module3_battery/direct_ar_model.py --p 10
4. Run Federated Learning 51-Client Benchmark: 
python src/federated_fedper/simulation_51trips.py --rounds 80 --early_stop 30
5. Launch Recommendation FastAPI Backend: 
uvicorn src.api.main:app --port 8000 --reload

ESP32 Edge Microcontroller Deployment

The three XGBoost models run sequentially on an ESP32 at 240 MHz in 8.65 ms total (M1: 3.35 ms, M2: 1.92 ms, M3: 3.38 ms). Wire the SH1106 OLED display as follows:

ESP32 to SH1106 OLED Pinout

  • • ESP32 GPIO 21 (SDA) → SH1106 SDA
  • • ESP32 GPIO 22 (SCL) → SH1106 SCL
  • • ESP32 3.3V & GND → SH1106 VCC & GND

Troubleshooting & Known Limitations

Q: Why does FedPer experience a cold-start cost on new vehicles?

A: Because a fresh personalization head begins without driver history (\(R^2 = 0.452\)). Performance peaks at round 30 before local overfitting occurs, so early stopping is essential.

Q: How does the capacity fade calibration behave at sub-zero temperatures?

A: The fade model was calibrated on 24–42°C cells from NASA/CALCE, whereas 85% of Munich driving windows are colder. Sub-zero operation requires conservative Arrhenius scaling.
